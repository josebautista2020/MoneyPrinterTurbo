# kids-puppies vertical

Vertical-specific policies, prompts, creative assets and configuration for the kids-puppies product live here.

This vertical may depend on reusable Content Studio contracts/extensions. Reusable core/extensions must never depend on this vertical.

All publishable output from this vertical requires kids-safety review and human approval before publishing.

Approved character and location reference images live in `assets/references`.
Their repository-relative paths, review status, dimensions, provenance, and
SHA-256 values are recorded in `consistency/reference_catalog.json`.
